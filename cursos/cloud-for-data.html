Cloud for Data: plataformas de dados na nuvem

Você vai aprender a montar uma plataforma de dados na nuvem: entender os serviços de cada provedor, controlar quem acessa o quê, escolher o armazenamento certo, processar e analisar dados com serviços gerenciados, rodar containers e funções serverless, e descrever toda a infraestrutura como código.

Cada módulo termina com uma peça da plataforma no ar. No fim, você tem uma arquitetura de dados completa, criada por Terraform, documentada e publicada no seu GitHub.

Sobre o conteúdo

Qual provedor de nuvem o curso usa?
Os conceitos valem para AWS, Google Cloud e Azure, e mostramos o serviço equivalente em cada um. Os exercícios práticos usam um provedor principal.
Vou ter que pagar pela nuvem?
Os exercícios foram pensados para as camadas gratuitas. Você configura alertas de custo no primeiro módulo e aprende a destruir os recursos com Terraform ao fim de cada aula.
O curso prepara para certificação?
Ele cobre boa parte dos fundamentos cobrados nas certificações de dados em nuvem, mas não é um preparatório para prova. O foco é saber montar e operar a plataforma.
Qual a diferença para o curso de Data Engineering?
Data Engineering foca em pipelines, modelagem e qualidade dos dados. Cloud for Data foca na infraestrutura onde isso roda: rede, segurança, serviços gerenciados, containers e infraestrutura como código.
E se o curso não for o que eu esperava?
Você tem 7 dias de garantia com reembolso integral, conforme o art. 49 do Código de Defesa do Consumidor.
